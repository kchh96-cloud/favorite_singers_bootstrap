# My Favorite Singers — Bootstrap 5

## Project files
- `index.html` — page layout and Bootstrap 5 links
- `js/main.js` — singer data and code that fills the table
- `images/music-stage.svg` — image used in the first column

## Run the website
Open `index.html` in a web browser. An internet connection is needed to load Bootstrap from its CDN.

## Customize
Edit the `singers` array in `js/main.js` to change the artists, songs, birthdays, or hometowns.
